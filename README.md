# SE Website Making Task — Umesh Chandra Reddy

## Student Project Hub
A responsive student portfolio + project management website created for the SE Website Making Task 2026–27.

## Database implementation
This project **clearly includes a database** using the browser's **IndexedDB API** (`UCRStudentHubDB`).

The database stores:
- Project records
- Contact/message records
- Created timestamps
- Project technology details

The website demonstrates database operations:
- **Create** — add projects/messages
- **Read** — display saved records
- **Delete** — clear records

No private database credentials are stored in the source code.

## Technologies
HTML5, CSS3, JavaScript, IndexedDB, Git/GitHub, Vercel.

## Run
Open `index.html` in a modern browser. Use the **Database** section to add a project or submit a contact message. Refresh the page to verify that IndexedDB keeps the records.

## Deployment
The project is static and can be deployed on Vercel without a build command.
